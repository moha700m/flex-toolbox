# عدّة فلكس · Flex Toolbox

تطبيق iOS مستقل (SwiftUI، iOS 17+، آيفون فقط) بأدوات تفتيش وتعديل **داخل صندوق رمل التطبيق**. IPA غير موقّع لـ ESign.

## وش فيه؟
- **مفتش IPA**: افتح `.ipa` من الملفات → Info.plist / صلاحيات / URL schemes / أطر / شجرة ملفات → عدّل الاسم أو المعرف أو الإصدار، احذف أو أضف ملفات، صدّر IPA جديد وشاركه لـ ESign.
- **عارض/محرر** plist و JSON و SQLite و Hex.
- **متصفح ملفات** Documents / Library / tmp الخاصة بالتطبيق.
- **محرر UserDefaults** للتطبيق نفسه.
- **مختبر HTTP** (طريقة، رابط، ترويسات، محتوى، رد منسّق، سجل).
- **معلومات الجهاز** و عارض Hex/نص.

## حدود صريحة
- ما يقدر يقرأ أو يعدّل تطبيقات ثانية مثبتة (قيود iOS).
- تعدّل فقط IPA تفتحه بنفسك ثم ترجعه لـ ESign.
- تطبيقات App Store تحتاج IPA مفكوك — مو متوفر هنا.
- إضافة dylib للـ IPA **ما تحقنها** في الثنائي تلقائياً.

## البناء
```bash
brew install xcodegen
xcodegen generate
# ثم افتح FlexToolbox.xcodeproj أو اعتمد على GitHub Actions
```
